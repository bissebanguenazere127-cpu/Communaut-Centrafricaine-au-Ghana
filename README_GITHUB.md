# CCG — Communauté Centrafricaine au Ghana

Version GitHub-ready avec une couche responsive globale.

## Déploiement GitHub Pages
1. Importer tout le contenu de ce dossier dans le repository.
2. Aller dans **Settings → Pages**.
3. Choisir **Deploy from a branch**.
4. Sélectionner `main` et `/ (root)`.
5. Enregistrer.

## Important
- Respecter les majuscules/minuscules des noms de fichiers.
- Les images doivent être dans leurs dossiers avec les chemins utilisés par le HTML.
- Le site est statique : HTML/CSS/JS fonctionne directement avec GitHub Pages.
